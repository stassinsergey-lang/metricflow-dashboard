# MetricFlow

An interactive revenue-operations dashboard for subscription businesses. It presents MRR, ARR, retention, churn, customer health and account activity in one responsive view.

## Highlights

- Responsive executive dashboard
- Interactive time-range controls and chart states
- Customer health and renewal-risk table
- Revenue mix and live activity components
- Zero dependencies: HTML, CSS and JavaScript only

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. This is an original portfolio project using representative sample data.
